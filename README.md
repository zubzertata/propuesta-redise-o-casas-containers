# Propuesta de Rediseño Web — Casas Containers

Propuesta conceptual de rediseño y mejora de la presencia digital de **Casas Containers**, desarrollada de manera independiente a partir de una revisión de su actual presencia web.

El objetivo de esta propuesta es explorar distintas formas de presentar la empresa, sus modelos de vivienda, características y proceso de cotización mediante una experiencia web más moderna, clara y orientada al usuario.

## Propuestas

El proyecto incluye dos alternativas visuales:

### Propuesta 01 — Moderna & Comercial

Una propuesta enfocada en una presentación limpia, clara y profesional, priorizando:

* Información de los modelos.
* Características y prestaciones.
* Comparación de alternativas.
* Proceso de compra/cotización.
* Llamados a la acción.
* Diseño responsive.

**Archivo:** `prototipo.html`

### Propuesta 02 — Industrial

Una propuesta con una identidad visual más marcada, inspirada en la estética industrial y arquitectónica asociada a las viviendas construidas con contenedores.

Busca generar una identidad más diferenciada mediante:

* Estética industrial.
* Mayor impacto visual.
* Presentación destacada de los modelos.
* Información comercial integrada al diseño.
* Elementos visuales orientados a generar interés y conversión.
* Diseño responsive.

**Archivo:** `prototipo industrial.html`

## Tecnologías

El proyecto está desarrollado utilizando tecnologías web estándar:

* HTML5
* CSS3
* JavaScript
* Diseño responsive

No requiere backend ni base de datos para la demostración visual.

## Estructura

```text
/
├── index.html
├── prototipo.html
├── prototipo industrial.html
└── README.md
```

`index.html` funciona como página de inicio y permite acceder a las distintas propuestas.

## Objetivo

Este proyecto fue desarrollado como una **propuesta visual independiente**, con el propósito de demostrar posibles oportunidades de mejora en la presentación digital de la empresa y explorar distintas direcciones de diseño.

Las propuestas no representan necesariamente una versión definitiva del sitio y pueden adaptarse según la identidad, información comercial y necesidades reales de la empresa.

---

> **Nota:** Este proyecto es una propuesta conceptual independiente y no corresponde al sitio web oficial de Casas Containers.
